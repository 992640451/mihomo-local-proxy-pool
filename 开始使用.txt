Proxy Port Manager — Windows 开始使用
English: START_HERE.txt

一、下载与解压
从项目 Releases 下载文件名含 windows-x64 的便携 ZIP；ARM 电脑选 windows-arm64。
下载入口：https://github.com/992640451/mihomo-local-proxy-pool/releases
不要选择 Source code（源码）；完整便携包自带运行环境，无需安装 Node.js、Git 或 Docker。
在 ZIP 上右键选择“全部解压”，放到自己的可写目录。不要在压缩包内直接运行。
请保留整个文件夹，不要只把一个 .cmd 文件移到桌面；需要桌面入口时可创建快捷方式。
这三个双击入口从 1.2.0 开始提供；旧版请参照随包的 PORTABLE_ZH.md。

二、启动并登录
1. 双击“启动管理器.cmd”，等待启动完成。
2. 第一次会显示“管理账号”和“管理密码”，请立即保存到密码管理器。
   密码只在生成时显示一次，不会保存为明文，也不会写入后台日志。
3. 就绪后默认浏览器会打开管理页面，用上面的账号和密码登录。
   默认地址：http://127.0.0.1:4173；若未自动打开，请使用启动窗口显示的地址。
4. 确认密码已保存后，按任意键关闭启动窗口。服务仍在后台运行。

三、日常使用
“启动管理器.cmd”：启动服务；已经正常运行时只打开页面，不重复启动。
“打开管理页面.cmd”：打开已运行的管理器，不会启动新服务。
“停止管理器.cmd”：停止管理器和内置 Mihomo，保留所有数据。
关闭浏览器或启动窗口不会停止代理。电脑重启后，需要再次双击启动；没有开机自启。

四、第一次配置代理
本项目不提供节点，请准备你有权使用的 Mihomo / Clash 订阅。
登录后：订阅 → 导入订阅；代理端口 → 新建端口池。
可用端口 17900、协议 Mixed；单节点选“手动选择”，主备切换至少需要两个节点。
保存后先“检测”监听，再“验证”实际出口。将对应代理地址填入需要代理的应用。
管理页面的 4173 端口不是代理端口；程序不会自动修改系统代理。

五、启动不了时
- 确认已完整解压；目录内应有 runtime、core、app 和 bin\ppm.cmd。请勿移动或删除它们。
  Windows 根目录只保留三个中文操作入口，底层命令行入口位于 bin 内；日常无需打开它。
  data 仍在解压根目录，不需要搬入 bin。
- 如果下载的是源码、系统架构不匹配，或文件被安全软件隔离，请重新核对官方便携包。
  遇到安全警告时先核对来源和发布校验和；不要为启动而关闭安全防护。
- 不要同时运行 Docker 版、旧版便携包或另一份管理器，它们可能占用相同端口。
- 保留窗口中的错误信息；详细日志位于 data\logs\application.log 和 data\logs\mihomo.log。
- 如提示已有进程但不健康，先双击“停止管理器.cmd”，确认停止成功后再启动。
- 密码不能从日志找回；请妥善保存，不要删除 data 或 config.env 来重新初始化。
  如已忘记，先停止并私下备份 data，再按 PORTABLE_ZH.md 的“忘记管理密码”说明联系维护者。
  不要上传配置、密码、订阅链接或 data，不要照搬 Docker 初始化命令。

六、更新与备份
先停止服务，再备份整个 data 文件夹（含密钥，不要公开分享）。
把新包解压到新目录，复制备份的 data 到新目录，再启动新版本。
验证新版本前保留旧目录和备份；不要同时运行两份实例，不要直接降级读取新数据库。

更多说明：README.md、PORTABLE_ZH.md；命令行操作仅为高级选项。
